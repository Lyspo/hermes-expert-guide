# Build conventions

Conventions for anyone — human or agent — working in this repo. They exist to protect two things: the **content's factual integrity** and the **interface's craft**. Both are the product.

> Site name is still `TBD` (decided at the design checkpoint). Until then, refer to the project as "the guide" in code and copy, never invent a name.

## The three non-negotiables

1. **No unsourced claims about Hermes.** Every command, config key, file format, and behavioural claim in `content/` traces to a source in `research/`. If a source can't be found, the sentence doesn't ship — write the gap into `research/gaps.md` instead.
2. **No AI slop.** See `design.md` for the banned-pattern list. If a component could have been generated by any model from a one-line prompt, it isn't done.
3. **Nothing breaks without JavaScript.** Content is server-rendered and complete; JS adds personalization and motion. Both are enhancements.

## Stack

Next.js 16 App Router (`output: 'export'`) · React 19 · TypeScript strict · Tailwind 4 (CSS-first `@theme`) · Motion 12 · GSAP 3.15 · content-collections · Pagefind · pnpm.

Static export means: no middleware, no ISR, no server actions, no route handlers, no `next/image` optimization. Every dynamic segment needs `generateStaticParams` plus `dynamicParams = false`. Redirects and headers live in `vercel.json`.

## Architecture rules

**Animation split — enforced by lint.** Components animate with Motion (`motion/react`, via `LazyMotion` + `m` on content routes). Scenes animate with GSAP (landing scroll narrative, scroll-scrubbed visualizations only), dynamically imported so content pages never ship it. Never animate one element with both.

**Every animation has a defined static end-state.** `prefers-reduced-motion` and the user's motion preference must land on that state, not on a broken half-state. This is a review checklist item, not a nice-to-have.

**Track adaptivity is CSS, not JS.** MDX renders *all* track variants into the HTML with `tk-*` classes; an inline script sets `data-track` on `<html>` before first paint; CSS hides what doesn't apply. Consequence: switching tracks costs one attribute write, crawlers index everything, and no-JS visitors see the complete labeled content. *Content* adapts via the CSS attribute; *chrome* (progress marks, "continue where you left off") adapts via React context with reserved-size placeholders so nothing shifts.

**All localStorage IO goes through `src/lib/storage.ts`** — one versioned key, Zod-validated reads, a migration registry, and try/catch everywhere (Safari private mode throws). Never touch `localStorage` directly elsewhere.

**The simulation engine is pure.** `src/lib/sim/timeline.ts` holds no DOM knowledge: one state `{virtualTime, playing, speed}`, everything else derived. That's what makes scrubbing exact and the engine testable.

## Content authoring

Lessons live at `content/curriculum/<NN-module>/<NN-lesson>.mdx` with typed frontmatter (`tracks`, `prerequisites`, `duration`, `hermesVersion`, `updated`). The build fails on dangling prerequisites or duplicate ordering — that's intentional.

- Real commands go in `<CommandBlock>`, which carries a version-provenance chip. Prose code goes in fenced blocks.
- `hermesVersion` records the Hermes release a lesson was verified against. Update it when you re-verify, not when you edit prose.
- Write for the reader who will put this on their résumé: precise, opinionated, no filler transitions, no "in today's fast-paced world".

## Verification

`pnpm verify` = typecheck + lint + unit + build + search index + OG images + link check. CI runs exactly this. A phase isn't done until it passes plus its own gate (see the plan).

Playwright runs against the **exported `out/`**, not the dev server — including a `javaScriptEnabled: false` pass asserting content completeness, and an axe sweep per template.

Performance budgets are Lighthouse CI assertions, not aspirations: lesson pages ≤130 kB initial JS / LCP ≤1.8 s / CLS <0.02; landing ≤200 kB pre-lazy / LCP ≤2.5 s. The WebGL canvas, if it ever exists, is never the LCP element.
